Privacy

Short version: this site sets no cookies, runs no analytics and makes no third-party requests. Nothing you do here is tracked.

What the site stores

One thing, and only if you use it. Choosing light or dark with the toggle writes a single value — theme — to your browser's local storage, so the page remembers your choice on your next visit. It never leaves your device and is not a cookie. Clearing site data removes it.

What the site does not do

  • No cookies of any kind, so no consent banner is needed.
  • No analytics, no tag manager, no advertising or social pixels.
  • No third-party requests. Fonts are served from this domain rather than a font CDN, so no outside party sees your visit.
  • No embedded video, comments or chat widgets.
  • No contact form, so nothing is submitted anywhere. Email addresses on the site are ordinary mailto: links.

The host does see your request

Worth stating plainly, because it is the one place data is processed. The site is served by GitHub Pages, so GitHub receives and may log the technical details of every request — IP address, user agent, the file requested — as any web host does. That processing is GitHub's, under its privacy statement. I have no access to those logs and no visitor statistics of my own.

Papers and machine readers

The PDFs on the publications page are free to read, link and cite. Crawlers that gather corpora for model training are asked in robots.txt to skip that directory; every paper's DOI is listed, so the canonical record stays reachable either way.

Questions

Write to karol@chlasta.pl. If this page ever stops matching what the site does, the discrepancy is a bug — please tell me.
